# C Programming — Practice Sessions

Learning C from the ground up as a foundation for reverse engineering, malware analysis, exploit development, and low-level systems programming.

## About This Repo

This is my working log as I build C fundamentals. The long-term goal is to move into offensive/defensive security work — reverse engineering, exploit dev, and systems-level programming — and solid C is the base everything else sits on.

Expect this repo to grow messy at times. It's a practice space, not a polished portfolio — code here reflects where I actually am at each stage, not a finished product.

## Goals

- Build a strong grasp of C syntax, memory management, and pointers
- Understand how C compiles down to machine behavior (stack, heap, registers)
- Practice reading and writing low-level code as prep for reverse engineering
- Eventually apply this toward exploit development and systems/security tooling

## Structure

Programs are organized as I go — expect folders or files grouped loosely by topic or session (e.g. basics, loops, arrays, pointers, memory) as the repo grows. Each `.c` file is a standalone practice program unless noted otherwise.

## Environment

- **Compiler:** GCC (MinGW-w64, UCRT runtime) on Windows
- **Editor:** VS Code with the C/C++ extension and Code Runner
- Compiled binaries (`.exe`, `.o`) are excluded via `.gitignore` — only source code is tracked

## Status

🟢 Actively learning — starting from fundamentals and building up. This README will get updated as the repo grows and I move into more advanced topics.

## Why This Repo Exists

Posting this publicly to stay consistent and accountable, and to have a visible trail of progress over time — from a first "hello world" to (eventually) more serious low-level and security-focused work.
